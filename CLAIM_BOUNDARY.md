# Claim Boundary

This repository exposes minimal public interfaces for bounded failure memory and structured cross-session memory.

It does not establish or release:

- A complete agent operating system or production deployment.
- A guarantee that an AI system never repeats a known failure.
- General, certified, or PAC-proven safety.
- Production orchestration, exact operational parameters, private prompts, private data, tuning history, customer systems, or deployment automation.

The decay equation in the README describes one rule-strength model. Its steady state is not a proof of end-to-end learning or safety.
